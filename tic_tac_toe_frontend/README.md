# Tic Tac Toe - Ocean Professional

A lightweight React implementation of a 3x3 Tic Tac Toe game with modern, minimalist styling.

## Features
- Two-player local play (X and O)
- Winner and draw detection
- Status bar and restart button
- Ocean Professional theme (primary #3b82f6, secondary #64748b, success #06b6d4, error #EF4444)
- Responsive board with subtle shadows, rounded corners, and smooth transitions

## Run
- npm start
- Open http://localhost:3000

## Structure
- src/App.js – main page and game logic
- src/components/Board.jsx – 3x3 grid
- src/components/Square.jsx – single square button
- src/index.css – theme and layout styles

No backend or environment variables required.
